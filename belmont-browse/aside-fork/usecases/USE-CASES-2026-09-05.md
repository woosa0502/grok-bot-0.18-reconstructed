### 자율성을 받치는 원본의 장치 (공식 컴포넌트 체인지로그, docs.aside.com/changelog/components)
- 루틴: cron 루틴 + **heartbeat 루틴**(기존 채팅을 새 맥락으로 깨움), 하루 여러 시각, 유한 루틴은 마지막 실행 뒤 자동 일시정지, 겹치면 건너뜀, 브라우저 기록에서 루틴 제안, 에이전트가 요청받아 루틴 일시정지/재개.
- **이벤트 트리거·인박스 웨이크**: 받은 알림(인박스)이 루틴을 깨움.
- 백그라운드: 데몬이 멈추면 브라우저 재시작 없이 자가 복구, 스트림 연속 실패 뒤 복구, 오래된 데몬 교체.
- 긴 작업: 컨텍스트 컴팩션(도구 루프 사이에도), 속도 제한 뒤 이어가기, 길이 초과 뒤 세션 재개, 반복 컴팩션 루프 방지.
- 채널: Slack/Discord/Telegram 원격 조종, 텔레그램 음성 메모 전사, 실행 중 메시지 전달, 하트비트를 채널 스레드에 게시.
- 에이전트 탭·서브에이전트: 에이전트의 탭·팝업을 묶고, 서브에이전트 활동을 따로 보여 줌, 강제 종료/크래시 뒤 남은 에이전트 탭 정리.
- 승인: review-before-action 모드, 승인 카드에 여러 줄 피드백, 미리보기에 대기 중 질문 표시; Deny > Ask > Allow 우선순위, Guard 기본.
- 알림: 포커스가 다른 데 있을 때 완료 알림, 보고 있으면 억제, 중복 방지.
