# 감사 방법론과 자기지적 보정 기록

> 상태: `PROVISIONAL_BASELINE`. 파일 목록과 SHA256은 재현 가능하지만, 파일별 정독을 기록했다는 워크플로 저널은 이 커밋에 포함되지 않았다. 이 문서의 추출 결과는 실사용 테스트 대상이며 PASS 증거가 아니다.

이 문서는 `grok-bot-verified-gap-ledger-2026-08-25.md` 감사의 재현 근거와, 외부 지적 6건에 대한 보정을 기록한다.

## 5. 남은 한계 (정직 고지)

- 원자성 위반 행 재분해 전이므로 총량은 ±수십 흔들릴 수 있다.
- 도달경로 분류는 아직 휴리스틱이다.
- electron-main/coordinator 일부는 재구성 저장소라 원본 대조가 불가해 overclaim 완전 배제는 못 한다.

## 6. 최종 확정 (v3) — 4·5절 잠정치를 대체

도달경로 분류는 배치 에이전트가 **소스를 직접 확인해 라벨을 확정**(휴리스틱 아님), 복합행동은 원자로 재분해 완료.

- 검증 누락 **1325행** → 재분해 후 **원자 행동 1500개** (+175)
- 도달경로(행 기준 / 원자 기준):
  - USER_REACHABLE: 794행 / 932원자
  - AGENT_REACHABLE: 405행 / 441원자
  - GATED: 45행 / 46원자
  - NOT_APPLICABLE: 9행 / 9원자
  - INTERNAL_ONLY: 72행 / 72원자
- 사용자 대면(USER_REACHABLE) 원자 932개. 기존 원장 344의 도달경로가 확정되지 않아 단순 합산 커버율은 사용하지 않는다.
- off-by-one·대소문자·출처·복합행동 4건은 v2에서, 도달경로·재분해 2건은 v3에서 종결. 지적 6건 모두 반영.
- 남은 근사: GATED/NOT_APPLICABLE 경계와 재구성 저장소의 electron-main/coordinator 원본 부재는 여전히 한계.

## 7. 후속 정규화 원장

기준선 CSV와 Markdown은 provenance 보존을 위해 덮어쓰지 않는다. 후속 사실 보정은 `grok-feature-registry-updates.jsonl`에 append-only로 기록하고 `grok-feature-registry-active.jsonl`로 materialize한다.

- `G1707`: baseline CSV의 `UNJUDGED`를 보존한 채 `GRU-000017`에서 `KEEP`으로 판정하고 `GBF-USR-000932`에 연결했다. 근거는 `source/packages/agent/git-pr-processing.ts`의 실제 직렬화 구현이다.
- 소스 참조: 임시/축약 참조 8행과 복합 shorthand 8행을 실제 저장소 경로로 보정했다.
- active 원장: 1,500개 모두 하나 이상의 현재 소스 경로가 해석된다.
- 제목 수: 546개 영역 중 75개는 원래 후보 행 수와 재분해된 원자 행 수가 다르다. 원문 제목은 보존하고 `grok-feature-heading-counts.json`에서 실제 원자 수를 제공한다.
