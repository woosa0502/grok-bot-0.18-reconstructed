# "쇼핑" 봇 초기 메모리 (앱 뜨면 그대로 심기)

봇이 **매번 되묻지 않게** 미리 심어둘 프로필. 앱/게이트웨이 살면 `addAgentMemory(<쇼핑봇id>, <내용>, tier="profile")`로 아래 조각을 하나씩 넣는다. (스킬에 이미 있는 규칙·공식은 중복 저장 안 함 — 여기엔 **이 사용자 고정정보**만.)

---

## A. 지금 바로 심을 조각 (확정된 사실)

**A1 — 사용자 기본**
> 사용자는 한국 거주. 영어·중국어 못 함(상품페이지·리뷰·판매자 문의 번역은 봇이 대행). 개인통관고유부호 보유. 우선순위는 미국·중국·한국 셋 다 균형. 물건 이름이나 용도만 말해도 봇이 국내→해외 순으로 알아서 찾는다. 링크는 있으면 지름길이지 필수 아님.

**A2 — 안전선(절대)**
> 돈 나가는 일(결제·주문확정·배대지/구매대행/쇼핑몰 계정가입·카드등록)은 절대 자동으로 하지 않는다. 봇은 소싱·번역·총비용계산·주문서·배대지 신청서 항목까지 준비하고, 마지막 실행은 사용자가 직접 누른다. 카드 원번호는 메모리에 저장하지 않는다("어떤 카드 쓸지"만 기록).

---

## B. 사용자에게 한 번만 받아서 심을 조각 (아직 값 없음 → 받으면 저장)

받는 즉시 profile memory로 저장하고, **다음 주문부터 안 물어본다.**

**B1 — 한국 배송 주소·우편번호**
> (받을 값) 국내 최종 배송지 도로명주소 + 우편번호. ⚠️ 개인통관고유부호 등록 주소·우편번호와 반드시 일치. 배대지·쇼핑몰 배송지에도 이 우편번호를 쓴다.

**B2 — 개인통관고유부호**
> (받을 값) P+12자리. 저장 여부는 사용자 결정 — 저장하면 주문서·배대지 신청서에 자동 채움, 원치 않으면 "보유"만 기록하고 신청 때 직접 입력.

**B3 — 결제수단 선호**
> (받을 값) 세팅 후 "미국·글로벌은 트래블로그(마스터), 중국 타오바오는 유니온페이 앱" 식으로 어떤 카드 쓸지. 원번호는 저장 안 함.

**B4 — 배대지·구매대행 계정**
> (받을 값) 미국 배대지 업체명 + 발급받은 사서함 주소. 중국은 구매대행 업체명 or 중국배대지 주소. 세팅 완료되면 저장 → 주문서에 자동으로 배송지로 들어감.

---

## C. 저장하지 않는 것 (매번 새로 확인)
- 환율, 재고, 실시간 배대지 무게요금, 특정 판매자/업체 평판·가격 → 그때그때 웹으로 확인. 오래된 값으로 단정하지 않음.

---

## 상태 체크(봇이 스스로 아는 진행도)
- [x] 통관부호 보유
- [ ] 한국 주소·우편번호 저장 (B1)
- [ ] 결제수단 세팅 (B3)
- [ ] 미국 배대지 세팅 (B4)
- [ ] 중국 경로 세팅 (B4)

봇은 세팅이 빈 상태에서 주문 요청을 받으면 → "먼저 이거 하나 세팅하자"로 **막힌 관문 1개**만 짚어준다. 다 되면 물건 이름만으로 바로 주문서까지 간다.
