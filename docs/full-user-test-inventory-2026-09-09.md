## 104. 데몬 호출(로그에서 관찰되는 것, 참고)

UI 조작 때 데몬 로그 `logs/daemon-YYYY-MM-DD.log`에 `tRPC <router>.<proc>`가 찍힌다. 오늘 관찰: sessions.list, sessions.shareStatus, routines.create/update/list, models.getSubscriptionUsage, analytics.isExperimentalEligible, passwordManager.vault.getSnapshot, passwordManager.settings.get/update, passwordManager.vault.createItem/updateItem/deleteItem/createVault/updateVault/deleteVault, passwordManager.auth.lockUiSession, passwordManager.search.checkPasswordExposure, accounts.current, settings.getAll/set, sessions.tabs.resolveByTarget, uiAttention.reportAgentManagerSessionAttention, models.ensureRoutingSelectionsAvailable. 각 UI 조작 뒤 어떤 호출이 나갔는지 `log.txt`에 붙인다(오류 등급이면 그 자체가 결함 후보).
