# Belmont Privacy Notice

Belmont is a personal assistant application run by its owner on their own computer.

- It is not offered to the public and has a single user: the person who installs it.
- Google account data (mail, calendar) that Belmont accesses through Google APIs is used only to answer that user's own requests and is stored only on the user's own machine.
- No data is sold, shared with third parties, or used for advertising.
- Access can be revoked at any time from the Google Account permissions page (https://myaccount.google.com/permissions), which also removes the stored tokens' usefulness.

Contact: the repository owner (see the GitHub profile of this repository).
